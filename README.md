## Sunnybox
We provide a powerful **Email API service** called **[Sunnybox](https://sunnybox.io)**.  
It's a fully hosted solution for handling email accounts: fetch, send, and analyze emails through a single, robust API. Perfect for developers who want easy, reliable email processing without the hassle of IMAP/MIME complexity.

## Usetix
We built the first **AI-native Event Ticketing Platform** called **[Usetix](https://usetix.io)**.  
It's a complete hosted service that lets you create a professional ticketing webshop, sell digital tickets (with full Apple Wallet & Google Wallet support), handle admissions via QR codes, and enjoy a built-in **AI assistant** that helps with event setup, descriptions, queries, and more — in both German and English. Designed for busy organizers who want simple, GDPR-compliant event management with transparent €1-per-ticket pricing, no lock-in, and real-time analytics.
